# ARMENIA — Տենդերների ամենօրյա ավտոմատ հավաքում

Այս պահոցը պարունակում է ամեն ինչ, ինչ պետք է **առանց ծրագրավորում իմանալու** ստանալ ծրագիր, որը.
- ամեն օր ինքը ստուգում է տենդերային կայքերը՝
  **PPCM «Հայտեր»** (`armeps.am/ppcm/public/bid-report`) և
  **«Մրցույթի հայտարարություն և հրավեր»** (`gnumner.minfin.am`), ինչպես նաև ցանկացած այլ կայք,
- բեռնում է **միայն նոր** հայտարարությունները (հոկտեմբերից սկսած արխիվի հետ միասին) և դասավորում է
  թղթապանակներով՝ ըստ օրվա ու կատեգորիայի,
- դուրս է գրում **ապրանքը/առարկան (նպատակը), հեռախոսահամարները, էլ. փոստերը**, ծածկագիրը,
  վերջնաժամկետը և կարգավիճակը Excel/CSV աղյուսակում, իսկ «Հայտեր»-ի տվյալները (մասնակից, ՀՎՀՀ,
  երկիր, հայտի գումար)՝ առանձին `MASTER-Հայտեր.csv` աղյուսակում։

## ⚖️ Կանոններ

- Բեռնվում են միայն **հանրային** տվյալներ։
- Հարցումների միջև դադարը (կարգավորելի է) պահպանում է կայքերը ծանրաբեռնվածությունից։
- Հայտարարությունների հեղինակային իրավունքը պատկանում է աղբյուրին. տվյալները՝ միայն անձնական/աշխատանքային օգտագործման համար։

## 🇬🇧 Summary (English)

This repository contains a ready-to-use master prompt (`prompts/`), an illustrated step-by-step guide in Armenian (`guide/`), and a working starter bot (`bot/`) that daily scrapes Armenian tender sites, saves only new announcements into date/category folders, and extracts purpose, phone numbers and e-mails into a CSV/Excel report.
