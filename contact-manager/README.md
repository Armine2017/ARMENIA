# Անձնական կոնտակտների կառավարման օգնական

Այս պանակը պահում է կոնտակտների բազայի **կառուցվածքը**, **կանոնները** և **գործիքակազմը**։
Տվյալները լրացվում են միայն քո տրամադրած նյութերից։

## Ինչպես աշխատել

1. Ուղարկիր կոնտակտները՝ ազատ տեքստով, ցուցակով կամ CSV ֆայլով։
2. Ես վերադարձնում եմ՝
   - նոր գրառումները՝ պատասխանի ձևաչափով (աղյուսակ),
   - հնարավոր կրկնվողները՝ **առանց միավորելու**,
   - բացակայող դաշտերի ցանկը,
   - «Ստուգման ենթակա» / «Երկիրը ստուգել» նշումները։
3. Դու հաստատում ես՝ որ գրառումներն են միավորվում, որ կատեգորիան է ճիշտ, որ համարն է միջազգային։
4. Ամեն օրվա վերջում տալիս եմ ամփոփում՝ նոր, կրկնվող և ստուգման ենթակա կոնտակտների քանակով։

**Ես չեմ կարող պնդել**, որ կոնտակտը ավելացվել է Notion-ում, հեռախոսում կամ այլ բազայում,
քանի դեռ այդ ինտեգրացիան իրականում միացված չէ։ Այս պանակի CSV-ն պատրաստ է ներմուծման/հաստատման համար։

## Ֆայլեր

| Ֆայլ | Ինչի համար է |
| --- | --- |
| `contacts.csv` | Գլխավոր բազան (ներկայումս դատարկ՝ վերնագրերով) |
| `contacts.py` | Ստուգում, կրկնվողների հայտնաբերում, ձևաչափի առաջարկ, ամփոփում |
| `extract_emails.py` | **Փոստարկղի արտահանումից կոնտակտների/հասցեների հավաքում ՄԵԿ ֆայլով** |
| `tests/sample_input.csv`, `tests/sample_mail.mbox` | Սինթետիկ (հորինված) տվյալ՝ միայն գործիքը փորձարկելու համար. **իրական կոնտակտ չէ** |
| `inbox/`, `reports/` | Նյութեր և հաշվետվություններ. **Git-ում չեն պահվում** |

## Գործիքակազմի օգտագործում

```bash
# 1) Կրկնվողների և անավարտ դաշտերի ստուգում (մուտքային ֆայլը չի փոփոխվում)
python3 contact-manager/contacts.py check contact-manager/contacts.csv \
    --out contact-manager/reports/check.md

# Հեռախոսները բաց տեսքով (միայն երբ ինքդ ես ստուգում)
python3 contact-manager/contacts.py check contact-manager/contacts.csv --show-phones

# 2) Օրվա ամփոփում
python3 contact-manager/contacts.py summary contact-manager/contacts.csv

# 3) Միջազգային ձևաչափի ԱՌԱՋԱՐԿ՝ հաստատված երկրով (AM=+374, RU=+7)
python3 contact-manager/contacts.py format contact-manager/contacts.csv --country AM \
    --out contact-manager/reports/formatted.csv
```

## Փոստարկղից կոնտակտների հավաքում (մեկ ֆայլով)

Եթե ունես փոստի արտահանում, այս գործիքը դրանից հանում է բոլոր անունները, էլ. հասցեները
և (ըստ ցանկության) ստորագրությունների հեռախոսները ու գրում **մեկ CSV ֆայլով**՝
խմբավորված կատեգորիաներով։

### Ինչպես ստանալ արտահանումը

| Աղբյուր | Քայլեր |
| --- | --- |
| Gmail | Google Takeout → «Mail» → արտահանել `.mbox` / `.zip` |
| Gmail (միայն կոնտակտներ) | Google Contacts → արտահանել CSV |
| Outlook / Thunderbird | Փոստարկղի արտահանում `.mbox` / `.eml` / `.pst` (`.pst`-ը նախ փոխարկել `.mbox`) |
| Այլ ծրագիր | Ցանկացած `.csv` / `.txt` ցանկ, որում հասցեներ կան |

### Աշխատանքի կարգը

1. Արտահանման ֆայլը դիր `contact-manager/inbox/` պանակում (Git-ը այն **չի** պահի)։
2. Գործարկիր՝
   ```bash
   python3 contact-manager/extract_emails.py \
       --input contact-manager/inbox/արտահանում.zip \
       --phones \
       --against contact-manager/contacts.csv \
       --out contact-manager/reports/email-contacts.csv
   ```
3. Տերմինալում կտեսնես ամփոփումը **դիմակավորված** (հասցեները, օր.՝ `al…@example.com`)։
4. Ֆայլը (`reports/email-contacts.csv`) կպարունակի ամբողջական հասցեները՝ ներմուծման/հաստատման համար։
5. Հաստատի՛ր ինձ, թե որ տողերն են իրական կոնտակտ և ո՞ր կատեգորիան է ճիշտ, և միայն դրանից հետո կմիավորենք `contacts.csv`-ի հետ։

### Հրահանգներ

| Հրահանգ | Իմաստ |
| --- | --- |
| `--input` | `.mbox` / `.eml` / `.zip` (Takeout) / `.csv` / `.txt` կամ պանակ |
| `--out` | Արդյունքային ՄԵԿ ֆայլը (լռելյայն՝ `reports/email-contacts.csv`) |
| `--against contacts.csv` | Նշում է այն հասցեները, որ արդեն կան բազայում («ՄԻԱՎՈՐՈՒՄ ՉԻ ԿԱՏԱՐՎԵԼ») |
| `--phones` | Ստորագրություններից հեռախոսահամարների հայտնաբերում |
| `--from-body` | Հասցեներ նաև նամակի մարմնից (ստորագրություններ) |
| `--min-count N` | Թողնել միայն N և ավելի հանդիպում ունեցող հասցեները |
| `--me adres@example.com` | Բաց թողնել քո սեփական հասցեները (կրկնելի) |
| `--mask-file` | Ֆայլում էլ. հասցեները դիմակավորել (եթե ֆայլը կիսում ես) |
| `--show-emails` | Տերմինալում ցույց տալ ամբողջական հասցեները (լռելյայն՝ դիմակավորված) |
| `--max-messages N` | Սահմանափակել մշակվող նամակների քանակը (փորձարկման համար) |
| `--headers From,To,Cc` | Որ header-ներից հավաքել (կարգավորելի) |

### Արդյունքային ֆայլի սյունակները

15 հիմնական դաշտերը **+** 5 օժանդակ՝ `Դոմեն`, `Աղբյուր (header)`, `Հանդիպումներ`, `Առաջին անգամ`, `Վերջին անգամ`։

### Անվտանգության կանոններ (պարտադիր)

1. **Միայն կարդում է.** Մուտքային ֆայլերը երբեք չեն փոփոխվում, չեն ջնջվում, չեն տեղափոխվում։
2. **Ցանց չկա.** Միայն Python ստանդարտ գրադարան, ամբողջությամբ օֆլայն։ Ոչինչ չի ուղարկվում որևէ սերվերի։
3. **Ոչ մի գործողություն փոստարկղում.** Ոչինչ չի ուղարկվում, չի պատասխանվում, չի նշվում կարդացված, չի ջնջվում։
4. **Նամակների բովանդակությունը չի պահվում.** Միայն անուն/հասցե/հեռախոս/ամսաթիվ։ Հավելվածներն ու մարմինը չեն արտահանվում։
5. **Տերմինալում ամեն ինչ դիմակավորված է.** Ամբողջական հասցեները միայն արդյունքային ֆայլում են (իրավունքները՝ `600`)։
6. **Ցուցակներում չկան իրական տվյալներ.** Իրական արտահանումները Git-ում արգելված են (`.gitignore`) և երբեք չեն pushվի։
7. **Ոչ մի միավորում կամ ջնջում ավտոմատ չի կատարվում.** Միայն առաջարկներ և նշումներ։
8. **Երկիրը չի ենթադրվում։** Առանց հաստատման համարը մնում է անփոփոխ՝ «Երկիրը ստուգել»։

### Երաշխիքներ

- Մուտքային CSV-ն **երբեք** չի փոփոխվում. `format`-ը գրում է **նոր** ֆայլ, սկզբնական համարները մնում են իրենց սյունակներում։
- Ոչ մի գրառում չի **միավորվում** կամ **ջնջվում** ավտոմատ. ցուցադրվում են միայն խմբեր և զույգեր։
- Երկիրը չի ենթադրվում. առանց հաստատման համարը մնում է անփոփոխ՝ «Երկիրը ստուգել» նշումով։
- Նույն անունը տարբեր համարով = **հնարավոր** կրկնվող, ոչ հաստատված նույն մարդ։
- Հաշվետվություններում համարները դիմակավորված են (`--show-phones`-ով՝ բաց)։

## Կանոններ (համառոտ)

- Մի՛ հորինիր անուն, համար, ծննդյան օր կամ այլ տվյալ։
- Անավարտ տվյալը նշիր **«Ստուգման ենթակա»**։
- Հեռախոսի սկզբնական տարբերակը պահպանիր մինչև երկրի/ձևաչափի հաստատումը։
- Կարևորությունը (A/B/C) նշանակիր միայն հաստատումից հետո, եթե հստակ նշված չէ։
