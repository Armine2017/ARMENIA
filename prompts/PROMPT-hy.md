# 📋 ԳԼԽԱՎՈՐ PROMPT — «Ամենօրյա տենդերային մոնիտոր»

> պատճենիր և անփոփոխ տեղադրիր AI օգնականի դաշտում (Arena.ai, ChatGPT, Claude, Gemini) ու սեղմիր Enter։

Դու փորձառու Python ծրագրավորող ես, վեբ-սկրեյպինգի (web scraping) և Windows-ի աշխատանքի ավտոմատացման մասնագետ։ Ես ծրագրավորող չեմ, ուստի ինձ տուր պատրաստի, միանգամից աշխատող ֆայլեր և պարզ, հայերեն հրահանգներ։

## ԽՆԴԻՐ

Կառուցիր ինձ համար «տենդերային մոնիտոր» ծրագիր, որը.

1. **Ամեն օր**, իմ նշած ժամին (լռելյայն՝ 08:00), ինքնուրույն ստուգում է իմ թվարկած կայքերը և բեռնում **միայն նոր հրապարակված** հայտարարությունները (տենդերներ, գնումների հայտարարություններ, հրավերներ, մրցույթներ)՝ վերջին ստուգումից հետո հրապարակվածները։
2. Ամեն հայտարարություն պահպանում է իմ համակարգչում որպես առանձին ֆայլ (ամբողջական տեքստով .txt և/կամ .html)՝ խմբավորված թղթապանակներում հետևյալ սխեմայով.
   `Tenders/<ԱՄՍԱԹԻՎ>/<ԿԱՏԵԳՈՐԻԱ>/<ԱՂԲՅՈՒՐ>_<ՎՐՆԱԳԻՐ>.txt`
   Կատեգորիաները որոշվում են իմ նշած բանալի բառերով (օր.՝ «շինարարություն», «ՏՏ», «բժշկական», «ծառայություններ», «տրանսպորտ»…)։
3. Ամեն հայտարարությունից դուրս է գրում ամենակարևոր տվյալները և գրում ընդհանուր **Excel/CSV աղյուսակում**.
   - հրապարակման ամսաթիվ,
   - պատվիրատու կազմակերպությունը,
   - **գնման նպատակը / առարկան** (հայտարարության վերնագիրն ու ամփոփումը),
   - ընթացակարգի ծածկագիրը (եթե կա),
   - հայտ ներկայացնելու վերջնաժամկետը,
   - **հեռախոսահամար(ներ)ը**,
   - **էլ. փոստի հասցե(ներ)ը**,
   - սկզբնաղբյուրի հղումը,
   - պահպանված ֆայլի ճանապարհը։
4. Ամեն աշխատանքի վերջում ստեղծում է **օրական ամփոփագիր** (քանի նոր հայտարարություն, որ կայքից, որ կատեգորիայում) և ցույց տալիս էկրանին + պահպանում ֆայլով։
5. **Երբեք չկրկնվելու** համար հիշում է արդեն բեռնված հայտարարությունները առանձին ֆայլում (`seen.json`)։

## ԱՂՅՈՒՐՆԵՐ (խմբագրիր այս ցանկը ըստ քո կարիքի)

1. `https://armeps.am/ppcm/public/tenders` — ARMEPS, հանրային տենդերներ
2. `https://gnumner.minfin.am/hy/page/norutyunner/` — Ֆինանսների նախարարություն, հայտարարություններ
3. `https://procurement.minfin.am/hy/page/hraverum_katarvats_popokhutyunner/440` — փոփոխություններ/հրավերներ
4. <ԱՅՍՏԵՂ ԱՎԵԼԱՑՐՈՒ ՔՈ ԿԱՅՔԵՐԸ, մեկական տողով>

Կանոն քեզ համար. նախ ստուգիր՝ կայքն ունի RSS, API կամ JSON էնդփոինտ — օգտագործիր դրանք։ Չունի՝ վերլուծիր HTML-ը (`requests` + `BeautifulSoup`)։ Բովանդակությունը JavaScript-ով է բեռնվում՝ օգտագործիր Playwright (headless զննարկիչ)։ Ամեն կայքի համար ընտրած մեթոդը գրիր config ֆայլում և բացատրիր ինձ մեկ նախադասությամբ։

## ՏԵԽՆԻԿԱԿԱՆ ՊԱՀԱՆՋՆՐ

- Python 3.10+; գրադարաններ՝ `requests`, `beautifulsoup4`, `lxml`, `pandas`, `openpyxl` (Playwright՝ միայն անհրաժեշտության դեպքում)։
- Իմ բոլոր կարգավորումները՝ **մեկ ֆայլում** (`config.json` կամ `config.yaml`)՝ կայքերի ցանկ, կատեգորիաներ ու բանալի բառեր, հիմնական թղթապանակ, աշխատանքի ժամ, հարցումների միջև դադարներ։
- Սխալների դիմացկունություն. եթե կայքը չի բացվում կամ փոխվել է՝ գրիր log ֆայլ և **շարունակիր մյուս կայքերով**. ամեն կայք փորձիր մինչև 3 անգամ՝ 10 վ դադարով։
- Քաղաքավարի սկրեյպինգ. 1.5–3 վ դադար հարցումների միջև, իրական User-Agent, կայքերը ծանրաբեռնել չի կարելի. բեռնել միայն հանրային տվյալներ։
- Կոդավորում՝ UTF-8. CSV-ը պահպանել `utf-8-sig`-ով, որպեսզի հայերենը Excel-ում ճիշտ բացվի։
- Թղթապանակների և ֆայլերի անուններում չօգտագործել Windows-ի արգելված նշանները՝ `\ / : * ? " < > |`։
- Ծրագիրն աշխատում է Windows 10/11-ում առանց լրացուցիչ կարգավորումների։

## ՀԱՆՁՆՎՈՂ ՖԱՅԼԵ (տուր բոլորը)

1. `tender_bot.py` — հիմնական ծրագիրը (մեկ ֆայլ, հայերեն մեկնաբանություններով),
2. `config.json` — կարգավորումներ՝ իմ կայքերով և կատեգորիաներով,
3. `requirements.txt` — գրադարանների ցանկ,
4. `SETUP.bat` — մեկ կտտոցով տեղադրում է գրադարանները,
5. `RUN.bat` — մեկ կտտոցով գործարկում է ծրագիրը,
6. `README-hy.md` — հայերեն հրահանգներ քայլ առ քայլ (նկարներով/սխեմաներով). ինչպես գործարկել, որտեղ տեսնել արդյունքը, ինչպես ավելացնել նոր կայք կամ կատեգորիա, ինչպես դնել ամենօրյա ավտոմատ գործարկում Windows Task Scheduler-ով,
7. Թեստ. գործարկիր ծրագիրը 1 կայքով (կամ ինտերնետ չկա՝ լոկալ օրինակ ֆայլով) և ցույց տուր աղյուսակի ու թղթապանակների օրինակը։

## ԱՇԽԱՏԱՆՔ ԿԱՐ

Քայլ 1. Եթե ինչ-որ բան պարզ չէ՝ նախ ինձ տուր կարճ հարցեր (ո՞ր կայքերը, ո՞ր կատեգորիաները, ո՞ր թղթապանակը)։
Քայլ 2. Ցույց տուր պլանը (որ կայքի համար որ մեթոդը) և սպասիր իմ «այո»-ին։
Քայլ 3. Հանձնիր վերը նշված ֆայլերը։
Քայլ 4. Բացատրիր 5–10 պարզ քայլով, նկարներով, ինչպես գործարկել իմ համակարգչում։
Քայլ 5. Եթե կայքը փոխվի կամ ծրագիրը կոտրվի՝ ես կուղարկեմ սխալի տեքստը, դու կուղղես։

## ԼԱՑՈՒՑԻՉ (եթե հնարավոր է)

- Օրական ամփոփագիրը իմ էլ. փոստին կամ Telegram-ին ուղարկելու հնարավորություն։
- «Միայն իմ բանալի բառերով» ռեժիմ. բեռնել միայն այն հայտարարությունները, որոնք պարունակում են իմ բառերը (օր.՝ «ճանապարհ», «ծրագրակազմ»)։
- «Ամբողջ արխիվը սկզբից» ռեժիմ՝ մեկ անգամ ամեն ինչ բեռնելու համար։
