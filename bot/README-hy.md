# 🤖 ՏԵՆԴԵՐԱՅԻՆ ՄՈՆԻՏՈՐ — պատրաստի բոտի հրահանգ (հայերեն)

Այս թղթապանակում կա **ամբողջովին պատրաստ** ծրագիր, որը.
- ամեն օր ստուգում է կայքերը,
- պահպանում է **միայն նոր** հայտարարությունները թղթապանակներում,
- դուրս է գրում **նպատակը, հեռախոսահամարները, էլ. փոստերը** CSV աղյուսակում,
- տպում է օրական ամփոփագիր։

---

## 🚀 Արագ մեկնարկ (3 րոպե)

1. **Տեղադրիր Python-ը** — `python.org/downloads` → «Download Python 3.x» → տեղադրման ժամանակ **նշիր «Add python.exe to PATH»** վանդակը։
2. Այս թղթապանակը (ամբողջ `bot` պանակը) պատճենիր քո համակարգչին, օր.՝ `C:\TenderBot`։
3. Կրկնակի սեղմիր **`RUN.bat`**։

Ամեն ինչ։ Կբացվի պատուհան, որը կստուգի կայքերը և վերջում կցուցադրի ամփոփագիրը։

> ⚠️ Առաջին անգամ նախ խորհուրդ ենք տալիս փորձարկել առանց ինտերնետի.
> հրամանի տողում գրիր `py tender_bot.py --demo`

---

## 📁 Ստացված արդյունքը

```
bot\
├── data\                          ← հայտարարությունների ֆայլերը (ըստ օրվա և կատեգորիայի)
│   ├── 2026-10-01\
│   │   ├── Շինարարություն\
│   │   │   └── ARMEPS_Դպրոցի-շենքի-վերանորոգում.txt
│   │   ├── ՏՏ և ծրագրակազմ\
│   │   └── Բժշկական\
│   └── 2026-10-02\
├── reports\                       ← ԳԼԽԱՎՈՐ ԱՐԴՅՈՒՆՔԸ
│   ├── Հաշվետվություն-2026-10-01.csv   ← Excel-ով բացվող աղյուսակ
│   ├── MASTER.csv                      ← բոլոր օրերի միացյալ աղյուսակ
│   ├── Ամփոփագիր-2026-10-01.txt       ← կարճ ամփոփագիր
│   └── logs\                           ← աշխատանքի պատմությունը ու սխալները
└── seen.json                      ← «հիշողությունը»՝ ինչ արդեն բեռնված է
```

**CSV-ը բացելու ճիշտ ձևը.** Excel → File → Open → ընտրիր ֆայլը։ Հայերենը կերևա ճիշտ (UTF-8):

**Աղյուսակի սյունակները.**
`Ամսաթիվ • Աղբյուր • Կատեգորիա • Կազմակերպություն • Նպատակ / Վերնագիր • Ծածկագիր • Վերջնաժամկետ • Հեռախոս • Էլ. փոստ • Հղում • Պահպանված ֆայլ`

## ⚙️ Կարգավորումները (`config.json`)

```json
{
  "run_time": "08:00",              // ամենօրյա գործարկման ժամը (--loop ռեժիմի համար)
  "delay_seconds": 2,               // դադար հարցումների միջև (քաղաքավարի սկրեյպինգ)
  "fetch_detail_pages": true,       // բացել նաև ամեն հայտարարության էջը՝ հեռախոս/էլ.փոստ գտնելու համար
  "only_keywords": [],              // օր. ["ճանապարհ", "ծրագրակազմ"] — դատարկ = բոլորը
  "sources": [
    { "name": "ARMEPS", "url": "https://armeps.am/ppcm/public/tenders", "kind": "html" },
    { "name": "MinFin", "url": "https://gnumner.minfin.am/hy/page/norutyunner/", "kind": "html" }
  ],
  "categories": {
    "Շինարարություն": ["շին", "կառուց", "վերանորոգ"],
    "ՏՏ և ծրագրակազմ": ["համակարգիչ", "ծրագր", "սերվեր"],
    "Բժշկական": ["բժշկ", "դեղ", "հիվանդանոց"],
    "Տրանսպորտ": ["տրանսպորտ", "մեքենա", "ճանապարհ", "վառելիք"],
    "Ծառայություններ": ["ծառայություն", "սպասարկում", "խորհրդատվ"],
    "Այլ": []
  }
}
```

- **նոր կայք ավելացնել.** `sources` ցանկում ավելացրու նոր տող՝ անուն + հասցե։
- **RSS ունեցող կայք.** `"kind": "rss"` դիր, և ծրագիրը կկարդա RSS-ը։
- **լոկալ օրինակ ֆայլ.** `"kind": "file"` և `"url": "samples/whatever.html"`։

## ⌨️ Հրամաններ

| Հրաման | Ինչ է անում |
|---|---|
| `py tender_bot.py` | մեկ անգամ ստուգում է բոլոր կայքերը |
| `py tender_bot.py --demo` | փորձարկում լոկալ օրինակներով (առանց ինտերնետի) |
| `py tender_bot.py --loop` | մնում է բաց և ամեն օր `run_time`-ին ինքն է աշխատում |
| `py tender_bot.py --reset` | մոռանում է «հինը» և ամեն ինչ նորից բեռնում (ամբողջ արխիվ) |

Եթե պատուհանում հայերենը «տարօրինակ» է երևում, ամենևին խնդիր չէ. արդյունքի ֆայլերը ճիշտ UTF-8 են։

## 🕗 Ամենօրյա ավտոմատ աշխատանք (Windows)

**Տարբերակ Ա (ամենահուսալին).** թող `RUN.bat`-ը բաց մնա ամբողջ օրը։ Դրա համար ֆայլի մեջ `python tender_bot.py` տողը դարձրու `python tender_bot.py --loop`։

**Տարբերակ Բ (Task Scheduler).**
1. `Win+R` → `taskschd.msc` → Enter։
2. **Create Basic Task…** → Անունը՝ `TenderBot` →
3. **Daily**, ժամը՝ `08:00` →
4. **Start a program** →
   - Program/script՝ `python`
   - Add arguments՝ `tender_bot.py`
   - Start in՝ `C:\TenderBot`
5. Finish։

⚠️ Այդ պահին համակարգիչը միացած ու ինտերնետին միացած պետք է լինի։

## 🛠 Եթե ինչ-որ բան չաշխատի

| Խնդիր | Լուծում |
|---|---|
| `python` հրամանը չի գտնվում | Python-ը տեղադրիր «Add python.exe to PATH» վանդակով |
| Կայքը չի բացվում | Նայիր `reports\logs\` ֆայլը. ծրագիրը կշարունակի մյուս կայքերով |
| Հայտարարությունները շատ են ու ոչ թեմային | Լրացրու `only_keywords`-ը կամ խմբագրիր `categories`-ի բառերը |
| Հեռախոս/էլ. փոստ չկա աղյուսակում | Հեռախոսները հաճախ **հայտարարության առանձին էջում** են. համոզվիր, որ `fetch_detail_pages: true` է |
| Ծրագիրը նույն հայտարարությունը նորից է բեռնում | Ստուգիր, որ `seen.json` ֆայլը չի ջնջվել |
| Ուզում եմ ամեն ինչ ամբողջ սկզբից | Գործարկիր `py tender_bot.py --reset` |

## 🔧 Ինչպես զարգացնել հետագայում

Այս բոտը միտումնավոր պարզ է (աշխատում է միայն Python-ի ներքին մոդուլներով)։ Երբ ուզենաս ավելին, պատճենիր `tender_bot.py`-ի պարունակությունը և տուր AI օգնականին այս պատվերի հետ.

> *«Ահա իմ աշխատող բոտի կոդը։ Խնդրում եմ ավելացնել. 1) Excel (.xlsx) արտահանում, 2) ամեն օր ամփոփագիրն իմ էլ. փոստով/Telegram-ով ուղարկելը, 3) JavaScript-ով բեռնվող կայքերի աջակցություն Playwright-ով, 4) կրկնվող բառերի վերլուծություն։ Բոլոր փոփոխությունները բացատրիր հայերեն, և տուր ամբողջական ֆայլը։»*

Օգտակար գրադարաններ. `requests`, `beautifulsoup4`, `lxml`, `pandas`, `openpyxl`, `playwright` (դրանք արդեն նշված են `requirements.txt`-ում)։
