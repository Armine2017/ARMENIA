# ARMENIA

Անձնական կոնտակտների կառավարման օգնականի աշխատանքային պանակ։

- `contact-manager/` — կոնտակտների բազայի կառուցվածքը, կանոնները և գործիքակազմը
  (կրկնվողների ստուգում, հեռախոսահամարների միջազգային ձևաչափի առաջարկ,
  փոստարկղի արտահանումից կոնտակտների հավաքում մեկ ֆայլով)։

Սկսիր այստեղից՝ [`contact-manager/README.md`](contact-manager/README.md)։

> Իրական կոնտակտների արտահանումները (`.mbox`, `.zip`, `.eml`) և ստեղծվող հաշվետվությունները
