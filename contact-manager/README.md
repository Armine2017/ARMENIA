# Անձնական կոնտակտների կառավարման օգնական

Այս պանակը պահում է կոնտակտների բազայի **կառուցվածքը**, **կանոնները** և **գործիքակազմը**։
Տվյալները լրացվում են միայն քո տրամադրած նյութերից։

## Ինչպես աշխատել

1. Ուղարկիր կոնտակտները՝ ազատ տեքստով, ցուցակով կամ CSV ֆայլով։
2. Ես վերադարձնում եմ՝
   - նոր գրառումները՝ պատասխանի ձևաչափով (աղյուսակ),
   - հնարավոր կրկնվողները՝ **առանց միավորելու**,
   - բացակայող դաշտերի ցանկը,
   - «Ստուգման ենթակա» / «Երկիրը ստուգել» նշումները։
3. Դու հաստատում ես՝ որ գրառումներն են միավորվում, որ կատեգորիան է ճիշտ, որ համարն է միջազգային։
4. Ամեն օրվա վերջում տալիս եմ ամփոփում՝ նոր, կրկնվող և ստուգման ենթակա կոնտակտների քանակով։

**Ես չեմ կարող պնդել**, որ կոնտակտը ավելացվել է Notion-ում, հեռախոսում կամ այլ բազայում,
քանի դեռ այդ ինտեգրացիան իրականում միացված չէ։ Այս պանակի CSV-ն պատրաստ է ներմուծման/հաստատման համար։

| `contacts.py` | Ստուգում, կրկնվողների հայտնաբերում, ձևաչափի առաջարկ, ամփոփում |

## Գործիքակազմի օգտագործում

```bash
# 1) Կրկնվողների և անավարտ դաշտերի ստուգում (մուտքային ֆայլը չի փոփոխվում)
python3 contact-manager/contacts.py check contact-manager/contacts.csv \
    --out contact-manager/reports/check.md

# Հեռախոսները բաց տեսքով (միայն երբ ինքդ ես ստուգում)
python3 contact-manager/contacts.py check contact-manager/contacts.csv --show-phones

# 2) Օրվա ամփոփում
python3 contact-manager/contacts.py summary contact-manager/contacts.csv

# 3) Միջազգային ձևաչափի ԱՌԱՋԱՐԿ՝ հաստատված երկրով (AM=+374, RU=+7)
python3 contact-manager/contacts.py format contact-manager/contacts.csv --country AM \
    --out contact-manager/reports/formatted.csv
```

### Երաշխիքներ

- Մուտքային CSV-ն **երբեք** չի փոփոխվում. `format`-ը գրում է **նոր** ֆայլ, սկզբնական համարները մնում են իրենց սյունակներում։
- Ոչ մի գրառում չի **միավորվում** կամ **ջնջվում** ավտոմատ. ցուցադրվում են միայն խմբեր և զույգեր։
- Երկիրը չի ենթադրվում. առանց հաստատման համարը մնում է անփոփոխ՝ «Երկիրը ստուգել» նշումով։
- Նույն անունը տարբեր համարով = **հնարավոր** կրկնվող, ոչ հաստատված նույն մարդ։
- Հաշվետվություններում համարները դիմակավորված են (`--show-phones`-ով՝ բաց)։

## Կանոններ (համառոտ)

- Մի՛ հորինիր անուն, համար, ծննդյան օր կամ այլ տվյալ։
- Անավարտ տվյալը նշիր **«Ստուգման ենթակա»**։
- Հեռախոսի սկզբնական տարբերակը պահպանիր մինչև երկրի/ձևաչափի հաստատումը։
- Կարևորությունը (A/B/C) նշանակիր միայն հաստատումից հետո, եթե հստակ նշված չէ։
